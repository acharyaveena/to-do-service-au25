# Assignment 5.2 - Open API specification document

## Manually created Open API specification document

```yaml
openapi: 3.1.0
info:
  title: The dog database
  version: 0.0.1
  contact:
    name: Veena Acharya
servers:
  - url: http://localhost:3000
paths:
  /dogs:
    get:
      summary: Get all dogs
      operationId: getAllDogs
      responses:
        '200':
          description: "A list of dogs"
          content:
            application/json:
              schema:
                type: object
                properties:
                  dogs:
                    type: array
                    items:
                      type: object
                      properties:
                        id:
                          description: The dog's unique identifier.
                          type: string
                        breed:
                          description: The dog's breed.
                          type: string
                        color:
                          description: The dog's color.
                          type: string
                        weight:
                          description: The dog's weight in pounds.
                          type: integer
```
